5\. (16 points) The string matching problem can be formulated as the following. Given a text $T[1, \ldots, n]$ ($n$ characters) and a pattern $P[1, \ldots, m]$ ($m \leq n$) (both of which are strings over the same alphabet), find all occurrences of $P$ in $T$. We say that $P$ occurs in $T$ with shift $s$ if $P[1, \ldots, m] = T[s+1, \ldots, s+m]$.

(c) During preprocessing, the KMP algorithm computes a prefix function $\pi : \{1, \ldots, m\} \rightarrow \{0, \ldots, m-1\}$. What is the prefix function given the following text and pattern? (4 points)\
