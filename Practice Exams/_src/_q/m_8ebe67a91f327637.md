D\. According to the following program with fork() system call, What kind of messages will they print out? Assume printf uses line buffers, that is, unless explicit fflush(), the stdout stream remains in the buffer, until fflush or exit. Suppose all fork() system calls succeed.

```c
#include <stdio.h>
main()
{
    char buffer[1024]="";
    int i,pid;

    if (fork()==0) strcat(buffer,"a");
    fork();strcat(buffer,"b");
    if (fork() > 0) {
        strcat(buffer,"c");
        printf("%s\n",buffer);
        fflush(NULL);
    }
}
```
