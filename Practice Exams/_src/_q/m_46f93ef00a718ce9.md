2\. We have a possible implementation of the monitor mechanism using semaphores in the following.

i\. For each monitor, a semaphore mutex (initialized to 1) is provided. Another semaphore next (initialized to 0) is introduced to control the conditional variables.

ii\. Each external procedure F in the monitor is replaced by

```c
wait(mutex);
   ...
   Body of F
   ...
if (next_count>0)
    signal(next);
else
    signal(mutex);
```

iii\. For each condition variable x, we introduce a semaphore x_sem and an integer variable x_count, both initialized to 0. The operation x.wait() is implemented as

```c
x_count++;
if (next_count > 0)
    signal(next);
else
    signal(mutext);
wait(x_sem);
x_count--;
```

iv\. The operation x.signal() is implemented as

```c
if (x_count >0) {
    next_count++;
    signal(x_sem);
    wait(next);
    next_count--;
}
```

If the x.signal() operation is invoked by the process P, and there exists a suspended process Q associated with condition x. Please choose a correct description on the above implementation.

(a) Q either waits until P leaves the monitor or waits for another condition.\
(b) Both P and Q will be active within the monitor.\
(c) P either waits until Q leaves the monitor or waits for another condition.\
(d) P will leave the monitor immediately.\
(e) None of the above.
