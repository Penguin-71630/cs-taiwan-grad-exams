4\. Consider the following program. Please answer the following questions.

```
#include <stdio.h>
int data[]={8, 26, 5,77,1,61,11, 60, 15, 49, 19};
int n=10;
void a(int r)
{
  int e, j;
  e=data[r];
  for(j=2*r;j<=n;j*=2)  {
    if (j<n&&data[j]<data[j+1]) j++;
    if (e>=data[j]) break;
    data[j/2]=data[j];
  }
  data[j/2]=e;
}
int main(void)
{
  int i;
  for(i=n/2;i>=1;i--)
    a(i);
}
```

(12) What is the time complexity of the program where *n* is the number of integers in the array *data*?

(A) O(log n)\
(B) O(n)\
(C) O(nlog n)\
(D) O($\text{n}^2$)\
(E) None of the above.
