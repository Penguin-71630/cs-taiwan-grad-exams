17\. This problem is about the minimum spanning tree problem.

(50) Consider the following algorithm with the disjoint set data structure to find a minimum spanning tree.

```
MST(G, w)
1. A = empty set
2. For each vertex v Make-Set(v)
3. Sort the edges of G into non-decreasing order by weight
4. For each edge (u, v) in G taken in non-decreasing order by weight
5.     If ________________
6.          add (u, v) to A
7.          Union(u, v)
8. Return A
```

What is the missing statement in line 5?\
(A) u=v\
(B) Find-Set(u) = Find-Set(v)\
(C) Find-Set(u) == Find-Set(v)\
(D) Find-Set(u) != Find-Set(v)\
(E) u!=v
