(1) What is the time complexity of function NCTU?

```
void CS(int * a, int root, int n)
{
  int e=a[root];
  for(int j=2*root;j<=n;j*=2)
  {
    if (j<n&&a[j]<a[j+1])
      j++;
    if (e>=a[j])
      break;
    a[j/2]=a[j];
  }
  a[j/2]=e;
}

void NCTU(int * csie, int n)
{
  // csie is a pointer to an integer array with n+1 integers
  for(int i=n/2;i>=1;i--)
    CS(csie, i, n);
}
```

(A) $O(\log n)$\
(B) $O(n)$\
(C) $O(n\log n)$\
(D) $O(n^2)$\
(E) $O(2^n)$
