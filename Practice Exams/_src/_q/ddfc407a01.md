9\. (6%) Consider the equation $x_1 + x_2 + x_3 + x_4 = 13$.

(a) (2%) How many different integer solutions to the equation in which $x_i \geq 1$, $i = 1, 2, 3, 4$? (Note that the two solutions $x_1 = 5$, $x_2 = 4$, $x_3 = 3$, $x_4 = 1$ and $x_1 = 1$, $x_2 = 4$, $x_3 = 5$, $x_4 = 3$ are assumed to be different.)\
(b) (4%) How many distinct integer solutions in which $1 \leq x_i \leq 4$, $i = 1, 2, 3, 4$?
