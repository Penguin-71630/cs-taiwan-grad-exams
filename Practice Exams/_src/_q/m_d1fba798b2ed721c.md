5\. Let $\mathbf{A}$ be an $m \times n$ matrix, $\mathbf{x} \in \mathcal{R}^n$ denote a vector, and $L(\mathbf{x}) = \mathbf{Ax}$ be a linear transformation. $\mathbf{row(A)}$, $\mathbf{col(A)}$, and $\mathrm{N}(\mathbf{A})$ respectively represent the row space, the column space, and the null space of $\mathbf{A}$. $\mathbf{rank(A)}$ and $\mathbf{nullity(A)}$ respectively represent the rank and nullity of $\mathbf{A}$. $\mathbf{kernel}(L)$ and $\mathbf{range}(L)$ respectively represent the kernel and the range of $L$. If $V$ is a vector space/subspace, $\mathbf{dim}(V)$ denotes the dimension of $V$. Consider the following statements:

(A) $\mathrm{row}(\mathbf{A}) = \mathcal{R}^n$.\
(B) $\mathrm{col}(\mathbf{A}) = \mathcal{R}^m$.\
(C) $\dim(\mathrm{col}(\mathbf{A})) < m$.\
(D) $\mathbf{Ax} = \mathbf{0}$ has infinite solutions.\
(E) $\mathbf{Ax} = \mathbf{0}$ has exactly one solution.\
(F) $\mathbf{Ax} = \mathbf{0}$ has no solutions.\
(G) $\mathbf{Ax} = \mathbf{0}$ is an inconsistent system.\
(H) $\mathbf{Ax} = \mathbf{0}$ is a consistent system.\
(I) $\mathrm{N}(\mathbf{A}) = \emptyset$.\
(J) $\mathrm{rank}(\mathbf{A}) = m$.\
(K) $\mathrm{nullity}(\mathbf{A}) = m$.\
(L) $\mathrm{kernel}(L) = \mathcal{R}^n$.\
(M) $\mathrm{range}(L) \subseteq \mathcal{R}^m$.\
(N) $\mathbf{AA}^T$ is not symmetric.

(a) (**2 points**) Which statements are always false?

(b) (**2 points**) Which statements are always true?

(c) (**2 points**) Which statements are equivalent to the statement (B)?

(d) (**2 points**) What does the statement (L) imply about $L$?
