15\. This question is about Euclid's algorithm for greatest common divisor and its loop invariants.

Assume that the function procedure rem(x,y) computes the remainder of x divided by y, where x and y are integers and, $(0 \leq x)$ and $(0<y)$ is the pre-condition before being used.

Euclid's algorithm is as follows.

```
Euclid ( a, b)    Pre-condition: (0 < a) and (0 < b).
        1. m:= a;    n:= b;    r:= rem(m,n);
        2. while ( 0 < r) do
        3.             m:= n;    n:= r;    r:= rem(m,n);
        4. Return n
```

(43). Which of the following statements best explains why the algorithm must terminate?

(A) The conditional test in line 2 cannot always be true.\
(B) Since rem(m,n) is always less than n, line 3 assigns r with a value that is less than the previous value of r. So, the conditional test in line 2 cannot always be true.\
(C) A simple algorithm like this is unlikely to incur error of infinite loop.\
(D) If we print the value of r each time it is assigned at line 3, we will see that its value never increases. Therefore, the algorithm will terminate.\
(E) If we use a debugger to check the value of r, we will see that its value is strictly decreasing. Therefore, the algorithm will terminate.
