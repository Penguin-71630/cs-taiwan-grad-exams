22\. Let $f(n)$ and $g(n)$ be asymptotically positive functions. $T(n)$ is the time an algorithm takes for an input of size $n$. Which one of the following statement is not correct?

(A) For the two functions $f(n)$ and $g(n)$, either $f(n)=\mathrm{O}(g(n))$ or $f(n)=\Omega(g(n))$\
(B) $\lg(n^c) = \mathrm{O}(\lg n)$ for constant $c>0$\
(C) $n^c = \mathrm{O}(a^n)$ for constants $c>0$ and $a>1$\
(D) For any uniform cost RAM program $T(n) = \Omega(S(n))$, where $S(n)$ is the space an algorithm uses for an input of size $n$\
(E) $\max(f(n), g(n)) = \theta(f(n) + g(n))$
