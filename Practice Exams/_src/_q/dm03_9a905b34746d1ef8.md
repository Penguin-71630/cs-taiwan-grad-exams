6\. (5 points) Which of the following statements are TRUE?

(A) Given a square matrix $\mathbf{A}$, its eigenvectors associated with non-zero eigenvalues must be in its column space.\
(B) The shortest (minimal 2-norm) least-squares solution to a problem $\mathbf{Ax} = \mathbf{b}$ must be in the row space of $\mathbf{A}$.\
(C) For any non-zero real symmetric matrix $\mathbf{A}$, its singular value decomposition ($\mathbf{A} = \mathbf{U\Sigma V}^{\mathrm{T}}$) can be the same as its eigenvalue decomposition ($\mathbf{A} = \mathbf{S\Lambda S}^{-1}$).\
(D) For any non-zero real matrix $\mathbf{A}$, the singular value decomposition of $\mathbf{A}^{\mathrm{T}}\mathbf{A}$ can be the same as its eigenvalue decomposition.\
(E) If $\mathbf{A}$ is a full row rank matrix, then $\mathbf{AA}^{\mathrm{T}}$ must be positive definite.
