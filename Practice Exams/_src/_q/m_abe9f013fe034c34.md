i\. The maximum flow problem is in P\
ii\. If a problem is in P, it must also be in NP\
iii\. If a problem is in NP, it must also be in P\
iv\. If a problem is NP-complete, it must also be in NP

(A) i, ii\
(B) i, ii, iii, iv\
(C) i, iii, iv\
(D) i, ii, iv\
(E) i, iv
