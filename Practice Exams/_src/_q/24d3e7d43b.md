6\. (6%) Suppose we have $n$ ranges $[a_1, b_1]$, $[a_2, b_2]$, $\ldots$, $[a_n, b_n]$, where all $a_i$'s are negative, and all $b_i$'s are positive. We are asked to preprocess these ranges so that for any input value $x$, we can efficiently count the number of ranges containing $x$. Design an efficient representation of the ranges so that the desired counting can be done in $O(\log n)$ time. Your representation must take $O(n)$ space. Describe your representation and how to answer a query in $O(\log n)$ time in details.
