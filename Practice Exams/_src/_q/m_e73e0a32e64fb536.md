1\. Suppose that we use *struct node* to represent binary trees, and use function *unknown* to process a binary tree.

```
struct node
{
  int data;
  struct node * left, * right;
};
struct node * r;
void unknown(struct node *p)
{
  struct node * q;
  if (p->left!=NULL)
    unknown(p->left);
  if (p->right!=NULL)
    unknown(p->right);
  q=p->left;
  p->left=p->right;
  p->right=q;
}
```

(3) Suppose the binary tree is of *n* nodes. What is the time complexity of function *unknown*?

(A) O(log n)\
(B) O(n)\
(C) O(nlog n)\
(D) O($\text{n}^2$)\
(E) None of the above.
