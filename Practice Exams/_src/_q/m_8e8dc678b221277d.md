3\. (10%) Consider the Banker's algorithm for deadlock avoidance. The following is a snapshot of a system with four types of resources A, B, C, and D.

| | *Allocation* (*A B C D*) | *Max* (*A B C D*) |
|:---:|:---:|:---:|
| $P_0$ | 0 6 3 2 | 0 6 5 2 |
| $P_1$ | 0 0 1 2 | 2 0 3 2 |
| $P_2$ | 0 0 1 4 | 2 6 5 6 |
| $P_3$ | 1 0 0 0 | 1 7 5 0 |
| $P_4$ | 1 3 5 4 | 2 3 5 7 |

*Available* (*A B C D*): 1 5 2 0

**Allocation**: An $n \times m$ matrix defines the number of resources of each type currently allocated to each process. If ***Allocation***$[i][j]$ equals $k$, then process $P_i$ is currently allocated $k$ instances of resource type $Rj$.\
**Max**: An $n \times m$ matrix defines the maximum demand of each process. If ***Max***$[i][j]$ equals $k$, then process $P_i$ may request at most $k$ instances of resource type $Rj$.\
**Available**: A vector of length $m$ indicates the number of available resources of each type. If ***Available***$[j]$ equals $k$, then $k$ instances of resource type $Rj$ are available.

Suppose that the algorithm checks the processes in the order of $P_0, P_1, P_2, P_3, P_4$. Give the number of available resources of each type after each iteration of the banker's algorithm.
