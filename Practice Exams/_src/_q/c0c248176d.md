2\. (10%) Answer the following questions about AVL trees:

2-1 (2%) Which of the following statement(s) about AVL trees are true?

A. AVL trees are binary trees.\
B. AVL trees are heap structures.\
C. AVL trees are ideal for storing items of an ordered dictionary.\
D. AVL trees satisfy the height-balance property.

2-2 (2%) Which of the following statement(s) about the complexity of AVL trees are true?

A. The space complexity of AVL trees is $O(\mathrm{n})$\
B. The time complexity for searching an item in an AVL tree is $O(n\log n)$\
C. The time complexity for removing an item from an AVL tree is $O(\mathrm{n})$\
D. The time complexity for inserting an item into an AVL tree is $O(\log n)$

2-3 (6%) Let $\mathrm{N}_h$ represent the minimum number of nodes that can form an AVL tree of height $h$. $\mathrm{N}_1=1$, and $\mathrm{N}_2=2$. Show what's the height of AVL trees with n nodes for $h \ge 3$ using Big-O notation. Show how to derive your answer.
