15\. This question is about Euclid's algorithm for greatest common divisor and its loop invariants.

Assume that the function procedure rem(x,y) computes the remainder of x divided by y, where x and y are integers and, $(0 \leq x)$ and $(0<y)$ is the pre-condition before being used.

Euclid's algorithm is as follows.

```
Euclid ( a, b)    Pre-condition: (0 < a) and (0 < b).
        1. m:= a;    n:= b;    r:= rem(m,n);
        2. while ( 0 < r) do
        3.             m:= n;    n:= r;    r:= rem(m,n);
        4. Return n
```

(44). Which of the following statements best describes what is involved in proving that at line 4, n=gcd(a,b)?

(A) Euclid's algorithm has been around for thousands of years and no one has yet found any error. Hence, it must be correct.\
(B) Euclid's algorithm has been rigorously tested by many experimental computer scientists and it always gives correct outputs.\
(C) When line 4 is reached, r = 0. And the remainder of m divided by n must now be 0. This fact, in addition to the proper loop invariant, can be used to prove that n=gcd(a,b).\
(D) When line 4 is reached, n must attain the correct value because this is the last statement of the program to be executed.\
(E) n = gcd(a,b) is a loop invariant all the time. Hence, at line 4, n=gcd(a,b).
