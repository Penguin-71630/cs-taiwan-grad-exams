10\. **(5 points)** A matrix is said to be in reduced row echelon form, if

(1) the nonzero entry in each nonzero row is 1.\
(2) row *m* does not consist entirely of zeros, the number of leading zero entries in row *m+1* is greater than the number of leading zero entries in row *m*.\
(3) there are rows whose entries are all zero, they are below the rows having nonzero entries.\
(4) the first nonzero entry in each row is the only nonzero entry in its column.\
(5) its augmented matrix is treated as a homogeneous system.
