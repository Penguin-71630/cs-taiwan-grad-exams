(2) What is the time complexity of function `kerker(0,n-1)`?

```
int kerker(int * a, int x, int left, int right)
{
  // a is a pointer to an integer array with n integers
  if (left<=right)
  {
    int m=(left+right)/2;
    if (x<a[m])
      return kerker(a,x,left,m-1);
    else if (x>a[m])
      return kerker(a,x,m+1,right);
    return m;  }
  return -1;}
```

(A) $O(\log n)$\
(B) $O(n)$\
(C) $O(n\log n)$\
(D) $O(n^2)$\
(E) $O(2^n)$
