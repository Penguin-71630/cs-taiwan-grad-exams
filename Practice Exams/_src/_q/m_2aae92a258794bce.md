5\. (9%) Please derive the corresponding time complexity (Big-Oh) for each of the following six program segments.

(a).

```
k=0;
for (i=0;i<N;i++)
    for (j=0;j<i;j++)
        k++;
```

(b).

```
k=0;
for (i=0;i<N;i++)
    for (j=0;j<i*i;j++)
        for (z=0;z<j;z++)
            k++;
```

(c).

```
k=0;
for (i=1;i<N;i++)
    for (j=1;j<i*i;j++)
        if (j%i==0)
            for (z=0;z<j;z++)
                k++
```
