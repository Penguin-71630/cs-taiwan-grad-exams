1\. (5 points) If a nonzero matrix is said to be in reduced row echelon form, the properties of this matrix are

(A) the first nonzero entry in each nonzero row is 1.\
(B) if row $m$ does not consist entirely of zeros, the number of leading zero entries in row $m+1$ is greater than the number of leading zero entries in row $m$.\
(C) if there are rows whose entries are all zero, those rows are below the rows having nonzero entries.\
(D) the first nonzero entry in each column is the only nonzero entry in its row.\
(E) all of the above are true.
