16\. Consider the following code fragment:

```c
char a[100][100];
int i,j;

for(i=0;i<100;i++)
    for(j=0;j<100;j++)
        a[i][j]=0;
```

Let the operating system use demand paging for virtual memory. Now suppose that the array a[][] can use 99 frames, and the frame size is 100 bytes (chars). Initially the array is not in memory, and the page-replacement algorithm is LRU. Let the average disk service time per page fault is 10 ms, and the average memory access time is 10 μs. Let element placement of arrays be row-major. Consider the accessing of the array a[][], which of the following are *correct*?

(a) There are 10,000 page faults\
(b) The total disk service time is 1 second\
(c) The effective memory access time is 1.01 μs\
(d) The effective memory access time is 10.01 ms\
(e) Adding more frames will make this program run much faster
