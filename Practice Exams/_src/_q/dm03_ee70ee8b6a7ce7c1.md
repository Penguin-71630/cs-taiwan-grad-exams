7\. (5 points) Suppose $\mathbf{A}_{4\mathrm{x}4} = \mathbf{xy}^{\mathrm{T}}$ is a rank-1 real matrix with $\mathbf{x}^{\mathrm{T}}\mathbf{y} = 0$ and $\|\mathbf{x}\|_2 = \|\mathbf{y}\|_2 = 1$. Which of the following statements are TRUE?

(A) $\mathbf{A}$ must have a non-zero eigenvalue.\
(B) There must be an invertible eigenvector matrix $\mathbf{S}$ $(\mathbf{AS} = \mathbf{S\Lambda})$.\
(C) The nullspace of $\mathbf{A}$ contains its column space, i.e., $\mathrm{N}(\mathbf{A}) \supset \mathrm{C}(\mathbf{A})$.\
(D) $\mathbf{v} = \mathbf{x} + \mathbf{y}$ can be the shortest (minimal 2-norm) least-squares solution to some problem of the form $\mathbf{Av} = \mathbf{b}$.\
(E) When $\mathbf{A}$ is factorized by singular value decomposition (SVD) into $\mathbf{U\Sigma V}^{\mathrm{T}}$, the only non-zero singular value is 1.
