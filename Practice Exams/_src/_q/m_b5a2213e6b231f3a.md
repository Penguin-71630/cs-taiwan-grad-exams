12\. Algorithm K is as follows.

Input: G = (V,E), a connected undirected weighted graph with n vertices.\
Output: G'= (V, E'), a minimum weight spanning tree (also known as minimum spanning tree), where E' is a subset of E and spans every vertex in V.\
Initially E' is empty set.\
Repeat the following two steps until (V, E') becomes a tree:\
Step 1: Select one edge in E (and not in E') that does not form a cycle with those already in E' and is of the lowest weight among all such edges. Name the selected edge $e_i$.\
Step 2: $E' := E' \cup \{e_i\}$.

(34). Which of the following statements about algorithm K is correct?

(A) The output of K is guaranteed to be a minimum spanning tree if and only if no pair of edges in E is of the same weight.\
(B) The output of K is guaranteed to be a minimum spanning tree only if no pair of edges in E is of the same weight.\
(C) Let w(e) denote the weight of a given edge e. Let $T=(V, \{a_1,a_2,\ldots,a_{n-1}\})$ be a spanning tree of G, where $w(a_i) \leq w(a_{i+1})$ holds for $1 \leq i \leq n-2$. Then, the output of K is such that $w(e_i) \leq w(a_i)$ holds for $1 \leq i \leq n-1$.\
(D) Let w(e) denote the weight of a given edge e. Let $T=(V, \{a_1,a_2,\ldots,a_{n-1}\})$ be a spanning tree of G, where $w(a_i) \leq w(a_{i+1})$ holds for $1 \leq i \leq n-2$. Then, the output of K is such that $w(a_i) \leq w(e_i)$ holds for $1 \leq i \leq n-1$.\
(E) All greedy algorithms produce optimal outputs and algorithm K is a greedy algorithm, therefore the output of K is guaranteed to be a minimum spanning tree.
