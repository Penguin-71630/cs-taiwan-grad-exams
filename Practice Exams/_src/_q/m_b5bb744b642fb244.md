3\. Considering the following program segment, please answer the following questions.

```
int a[]={8, 26, 5,77,1,61,11, 60, 15, 49, 19};
int n=11;

int ptt(int x)
{
  int k=-1;
  int i=0;
  int j=n-1;
  do  {
    k=(i+j)/2;
    if (a[k]<=x)
      i=k+1;
    else
      j=k-1;
  } while (i<=j);
  return k;
}
```

(9) What is the time complexity of the function *ptt*?

(A) O(log n)\
(B) O(n)\
(C) O(nlog n)\
(D) O($\text{n}^2$)\
(E) None of the above.
