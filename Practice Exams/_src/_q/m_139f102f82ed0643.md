7\. (15%) Let G be a directed graph and w be the edge weights of G.

```
Mystery-Algorithm(G, w)
    1.
    create G' where G'.V = G.V ∪ {s},
        G'.E = G.E ∪ {(s, u): for u in G.V}}, and
        w(s, u) = 0 for u in G.V
    2.
    if Bellman-Ford(s) == False
        return "The input graph has a negative weight cycle"
    else:
        for each vertex v in G'.V:
            h(v) = distance(s, v) computed by the Bellman-Ford
        for each edge (u, v) in G'.E:
            w'(u, v) = w(u, v) + h(u) - h(v)
    3.
        D = new matrix of distances initialized to infinity
        for each vertex u in G.V:
            run Dijkstra(G, w', u) to compute distance'(u, v)
                                  for all v in G.V
            for each vertex v in G.V:
                D(u, v) = distance'(u, v) + h(v) - h(u)
      return D
```
