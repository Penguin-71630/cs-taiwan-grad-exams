1\. (8%) Consider the following C program.

```c
#include <stdio.h>
#include <unistd.h>

int value = 2;

int main()
{
  pid_t pid;

  do {

    /* fork a child process */
    pid = fork();

    if (pid == 0) {   /* child process */
      value--;
    }
    else {   /* parent process */
      printf("parent: value = %d", value); /* line A */
      fork();
      execlp("\bin\ls");
      /* execlp() loads a new program into memory
         (destroying the memory image of the program
         containing the execlp() system call). */
    }

  } while(value >= 0);

  return 0;
}
```

(a) (4%) After the initial parent process creates the first child process (in the do-while loop), what is the output at `line A`? Justify your answer.

(b) (4%) Including the initial parent process, how many processes are created by the program? Justify your answer.
