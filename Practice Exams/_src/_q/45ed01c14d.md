```
          slt     $t2,    $t0,     $t0      # set if less than
          bne     $t2,    $zero,   ELSE     # branch if not equal
          j       DONE                      # jump to
ELSE:     addi    $t2,    $t2,     2        # add immediate
DONE:     ...
```
