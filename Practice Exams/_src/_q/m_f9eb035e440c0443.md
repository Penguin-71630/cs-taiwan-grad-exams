26\. Let G = (V, E) be an undirected connected graph, where each edge $e$ has a given length $l(e)>0$. Let $s$ be a fixed vertex of this graph and let $\delta(v)$ be the length of a shortest path from s to $v$. Which one of the following statements is not correct?

(A) For each vertex $v \neq s$, there is an incident edge $e=(u,v)$ such that $\delta(v)=\delta(u)+l(e)$.\
(B) For each vertex $v \neq s$, choose one incident edge $e=(u,v)$ such that $\delta(v)=\delta(u)+l(e)$, the collection of these edges forms a spanning tree of G.\
(C) For each vertex $v \neq s$, choose one incident edge $e=(u,v)$ such that $\delta(v)=\delta(u)+l(e)$, the collection of these edges forms a minimum weight spanning tree of G.\
(D) Bellman-Ford algorithm can find a shortest path from $s$ to $v$ in this case.\
(E) Dijkstra's algorithm can find a shortest path from $s$ to $v$ in this case.
