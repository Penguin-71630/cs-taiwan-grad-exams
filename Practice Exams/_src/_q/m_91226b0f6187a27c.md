8\. (10%) A process is a program in execution. A process can be further divided into a ***text*** section, ***data*** section, ***heap***, and process ***stack***. Consider the below program written in C.

```c
#include <stdio.h>
#include <stdlib.h>
float float_array[10];
static double double_array[10];
int main(void)
{
    int num;
    scanf("%d",&num);
    int *int_array = (int*) malloc(num * sizeof(int));
    // Some lines are removed for space reason.
    return 0;
}
void foo1(int n)
{
    n = (n > 0)? 1 : 0;
    printf("%d", n);
}
void foo2()
{
    static int count = 0;
    count++;
    printf("%d", count);
}
```

Please fill in the following blanks with *text*, *data*, *heap*, or *stack*.

(a) The variable array "**float_array**" is stored in the \_\_\_\_\_\_\_\_\_\_ section.\
(b) The variable array "**double_array**" is stored in the \_\_\_\_\_\_\_\_\_\_ section.\
(c) The variable array "**int_array**" is stored in the \_\_\_\_\_\_\_\_\_\_ section.\
(d) The variable "**n**" is stored in the \_\_\_\_\_\_\_\_\_\_ section.\
(e) The variable "**count**" is stored in the \_\_\_\_\_\_\_\_\_\_ section.
