14\. When implementing the monitor with the signal and wait execution method, which of the following statements are *correct*? Assume for each monitor, a semaphore mutex (initialized to 1) is provided. Two semaphore variables next and x_sem are initialized to 0 and two integers next_count and x_count are initialzed to 0.

```c
/* Each external procedure F is replaced by: */
wait(mutex);
   ...
   Body of F
   ...
if (next_count>0)
    signal(next);
else
    signal(mutex);

/* x.wait() is implemented as: */
x_count++;
if (next_count>0)
  /* Line A*/
else
  /* Line B*/
wait(x_sem);
x.count--;

/* x.signal() is implemented as: */
if (x_count>0) {
   next_count++;
   /* Line C*/
   wait(next);
   next_count--;
}
```

(a) The statement of Line A is signal(mutex);\
(b) The statement of Line B is signal(next);\
(c) The statement of Line B is signal(mutex);\
(d) The statement of Line C is signal(x_sem);\
(e) The statement of Line A is wait(mutex);
