15\. This question is about Euclid's algorithm for greatest common divisor and its loop invariants.

Assume that the function procedure rem(x,y) computes the remainder of x divided by y, where x and y are integers and, $(0 \leq x)$ and $(0<y)$ is the pre-condition before being used.

Euclid's algorithm is as follows.

```
Euclid ( a, b)    Pre-condition: (0 < a) and (0 < b).
        1. m:= a;    n:= b;    r:= rem(m,n);
        2. while ( 0 < r) do
        3.             m:= n;    n:= r;    r:= rem(m,n);
        4. Return n
```

(42). We want to prove that this function procedure produces only correct output. In other words, we want to show that when line 4 is reached, n=gcd(a,b). Which of the followings is a proper loop invariant for this algorithm?

(A) gcd(m, n) = gcd(a,b)\
(B) gcd(a, m) = gcd( b,n)\
(C) n = gcd(a,b)\
(D) gcd(m,n) = min( gcd(a,b), rem(m,n) )\
(E) gcd(m,n) = max( gcd(a,b), rem(m,n) )
