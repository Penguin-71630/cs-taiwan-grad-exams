12\. Consider a system with five processes P0\~P4 and three resource type A, B, C. Suppose at time T0, the resource allocation state is:

| | Allocation (A B C) | MAX (A B C) | Need (A B C) | Available (A B C) |
|:---:|:---:|:---:|:---:|:---:|
| $P_0$ | 2 1 1 | 3 1 3 | 1 0 2 | 2 0 2 |
| $P_1$ | 0 1 1 | 3 2 1 | 3 1 0 | |
| $P_2$ | 1 0 0 | 1 0 4 | 0 0 4 | |
| $P_3$ | 0 1 2 | 2 1 2 | 2 0 0 | |
| $P_4$ | 1 0 0 | 1 1 0 | 0 1 0 | |

Which of the following statements are correct?

(a) <P4, P3, P2, P0, P1> is a safe sequence.\
(b) <P3, P0, P1, P4, P2> is a safe sequence.\
(c) <P0, P1, P2, P3, P4> is a safe sequence.\
(d) <P0, P2, P3, P4, P1> is a safe sequence.\
(e) There is no safe sequence.
