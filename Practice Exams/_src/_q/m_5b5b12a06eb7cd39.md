```c
int i, j;
char data[64][64];
for(i=0; i < 64; i++)
    for(j=0; j<64; j++)
        data[i][j] = 0;
```

(e) Assume that the system allocates four frames for the process, and the array is stored in the column major form. The page fault number by the second-chance algorithm is the same as that by first-in-first-out (FIFO) algorithm.
