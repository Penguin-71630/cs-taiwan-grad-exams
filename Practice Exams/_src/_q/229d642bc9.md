1\. (20 points) Prove, calculate or rank the asymptotic bounds for the following functions.

(a) (10 points) Given the n-th harmonic number $H(n)$:

$$H(n) = \sum_{k=1}^{n} 1/k \quad (n > 0),$$

prove $H(n) = O(\log n)$ and $H(n) = \Omega(\log n)$.

(b) (5 points) Give the asymptotically tight bound ($\theta-$notation) for the recurrence $T(n)$:

$$T(n) = 2T(n/2) + n/\log n \quad (\text{assume } T(1) = 1).$$

Show the derivation.

(c) (5 points) Rank the following functions $f_1 \ldots f_5$ by order of growth.\
If $f_i = O(f_j)$ $(i \neq j)$, then $f_i \prec f_j$.\
$f_1 = \log^2 n, \quad f_2 = n \log n, \quad f_3 = \sqrt{n},$\
$f_4 = \log(n!), \quad f_5 = (3/2)^n$\
Please complete the form: \_\_\_ $\prec$ \_\_\_ $\prec$ \_\_\_ $\prec$ \_\_\_ $\prec$ \_\_\_.
