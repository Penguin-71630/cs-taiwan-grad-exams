18\. Given an undirected weighted graph, let *U* be a set of edges and empty initially.

Let m be the edge number and n the vertex number of the input graph. Consider the following algorithm:

Repeat the following until the resulting graph becomes a single node.\
Step 1: For each node *u*, mark its lightest incident edge.\
Step 2: The marked edges form a forest *F*. Add the edges of *F* to *U*.\
Step 3: Contract each maximal subtree of *F* into a single node.

(50) What is *U* after the algorithm terminates?

(A) shortest path (B) maximum flow (C) minimum cut (D) minimum spanning tree (E) a maximum matching.
