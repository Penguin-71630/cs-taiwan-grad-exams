1\. (a) (10 points) Please translate the following two assertions into logical formulae. We consider natural numbers only. Assume that there is a predicate $IsPrime(x)$, which is true if and only if $x$ is a prime number. Hence you do not need to define prime numbers. An *interval*, denoted as $[a,b]$, is defined as the set $\{n \mid n \in N, a \le n \le b\}$. The size of this interval is $b-a+1$.

- There is a prime number in every interval whose size is $10^8$.
- There are infinite pairs of consecutive prime numbers $(p,q)$ satisfying $|p-q| \le 10^8$.

(b) (5 points) Are the above two assertions logically equivalent? Which must be false? Why?
