11\. This question is about loop invariants in proving algorithm correctness.

(30). Which of the following statements gives the best description of the concept of loop invariants?

(A) A loop invariant is an assertion about the program state at the beginning of each iteration of a while loop. And it must be stated in such a way that the assertion attains truth value initially and continues to attain truth value after each iteration of the while loop.\
(B) A loop invariant is an assertion about the program state at the beginning of each iteration of a while loop. And it must be stated in such a way that the assertion can attain changing values from one iteration to the next. In this way, the behavior of the while loop through every iteration can be observed and analyzed.\
(C) A loop invariant is a piece of code that is executed each time a while loop iteration is performed. It checks correctness of program execution and sends signal to operating system if and when program errors occur.\
(D) A loop invariant is an assertion built in the run-time environment that is constantly monitoring the performance of a program execution. When the program execution needs more resource, the assertion sends signal to the run-time environment.\
(E) A loop invariant is a piece of code within a while loop that is constantly monitoring the invariants of the program. When the value of the invariants falls out of an acceptable range, the piece of code will terminate its execution and then operating system will take over to handle the situation.
