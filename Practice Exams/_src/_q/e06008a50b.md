10\. (7%) Given the set $A = \{1, 2, 3, 4, 6, 12\}$, consider the partial ordering relation $R$ on $A$.

$$R = \{(x, y) \mid x \text{ divides } y\}.$$

(a) (3%) Draw the Hasse diagram for the partially ordered set $(A, R)$.\
(b) (4%) What is the length of the longest chain in the partially ordered set $(A, R)$? Suppose the length of the longest chains in $(A, R)$ is $n$, then the elements in $A$ can be partitioned into $n$ disjoint antichains. Please find one such partition.
