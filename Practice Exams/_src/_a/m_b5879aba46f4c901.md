(a) Thrashing: processes lack enough frames, page fault constantly and the system spends its time paging/switching instead of doing useful work\
(b) PFF: monitor each process's page-fault rate; above an upper bound give it more frames, below a lower bound take frames away; if no free frames, suspend (swap out) a process\
(c) Working-set model / load control: admit or schedule a process only if its working set fits in memory, otherwise suspend processes to reduce the degree of multiprogramming\
(d) Share memory among processes: shared code/libraries, copy-on-write fork, shared memory for common data, and reduce per-process heap/stack
