Using $E$ as the exclusive/modified state: $I\xrightarrow{\text{local read / BusRd}}S$, $I\xrightarrow{\text{local write / BusRdX}}E$, $S\xrightarrow{\text{local write / invalidate}}E$, $S\xrightarrow{\text{remote write}}I$, $E\xrightarrow{\text{remote read / supply, write back}}S$, $E\xrightarrow{\text{remote write / supply, write back}}I$. Self-loops: local reads in $S,E$, local writes in $E$, remote reads in $S$, and remote requests in $I$.\
Avoid false sharing by aligning/padding independently written variables into separate cache lines or using per-thread data.
