(a) Use edges $s\to c$, $c\to r$ for $(c,r)\in M$, and $r\to t$, all with capacity $1$. The maximum-flow value is the maximum number of assigned classes.\
(b) Any maximum-flow value is correct, but a fractional maximum flow need not directly encode an assignment (e.g. $K_{2,2}$ with flow $1/2$ on each class–room edge). Integral flows correspond to matchings; Ford–Fulkerson from zero preserves integrality, so its maximum flow gives a valid maximum assignment.
