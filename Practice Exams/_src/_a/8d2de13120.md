(a) DP: $P[i][s]$ = true iff some subset of the first $i$ integers sums to $s$; $P[i][s] = P[i-1][s] \lor P[i-1][s-a_i]$, $P[0][0]$ = true; fill $n \times m$ table, answer $P[n][m]$, $O(nm)$\
(b) Pseudo-polynomial: input size is $O(n \log m)$ bits, and $m$ is exponential in $\log m$
