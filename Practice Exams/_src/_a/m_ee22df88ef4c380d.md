(a) 以 OpenCL／CUDA 等 API 啟動 GPU kernel，經驅動程式及 DMA／互連（獨立顯卡通常為 PCIe）在 CPU、GPU 記憶體間搬移輸入與結果。\
(b) CPU、GPU 共享資料並各執行適合的工作，減少複製、同步開銷與耗電，提高異質平行運算效率。\
(c) 統一虛擬位址、共享實體記憶體及相容的位址轉譯，加入快取一致性、原子操作與記憶體排序支援；省去重複儲存與傳輸，但增加 MMU／一致性互連的成本、驗證複雜度及共享頻寬競爭。\
(d) 執行時由 JIT 將 HSAIL 最佳化並轉為當地 GPU 的原生指令；優點是跨 ISA 可攜、可依硬體與執行資訊最佳化，缺點是啟動延遲、編譯耗能／記憶體開銷及對執行環境的依賴。
