(a) Let $D(a,b,c)=(b-a)\times(c-a)$. Return TRUE iff the closed bounding boxes overlap and $D(p_1,p_2,p_3)D(p_1,p_2,p_4)\le0$, $D(p_3,p_4,p_1)D(p_3,p_4,p_2)\le0$; otherwise FALSE. Time $O(1)$, including touching/collinear cases.\
(b) Sweep sorted endpoints, maintaining active segments in a balanced tree by height. Test neighbors on insertion and the newly adjacent pair on deletion; stop upon intersection. Handle tied endpoints, vertical segments and collinear overlaps inclusively. Time $O(n\log n)$, space $O(n)$.\
(c) Cast a ray from the query point; odd crossing parity means inside, even means outside. Use half-open endpoint counting so vertices are not double-counted, and ignore horizontal edges for a horizontal ray. Time $O(n)$, extra space $O(1)$; convexity is not assumed.
