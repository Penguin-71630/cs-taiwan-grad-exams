Monolithic: all OS services (FS, drivers, networking, memory mgmt, scheduling) run in one kernel address space; microkernel: kernel keeps only IPC, basic scheduling, low-level memory, other services run as user-space servers.\
iOS: hybrid kernel (XNU = Mach + BSD); Android: Linux, monolithic (with loadable modules).\
Examples external to a microkernel: file systems, device drivers, network protocol stack, paging/virtual memory pager.
