(a) A process spends more time paging (page faults) than executing because it lacks enough frames; CPU utilization drops sharply.\
(b) Working set = set of pages referenced in the most recent Δ references (working-set window), approximating the locality of the process.\
(c) Give each process frames ≥ its WSS; if total demand $D=\sum WSS_i$ exceeds available frames, suspend (swap out) some process; otherwise admit more processes.
