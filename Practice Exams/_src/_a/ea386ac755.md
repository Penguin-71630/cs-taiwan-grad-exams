(a) Virtual memory with MMU/page tables (per-process address space, user/kernel protection bits) and privileged/user modes\
(b) It keeps execution units busy by running independent later instructions while earlier ones stall (e.g., cache misses), exploiting ILP\
(c) Benefit: avoids stalls on branches/long-latency ops, higher throughput; disadvantage: wasted work and power on mis-speculation, recovery cost, and leftover microarchitectural side effects\
(d) Exceptions come from e.g. illegal/privileged memory access, page fault, divide by zero, invalid opcode; the processor marks the instruction in the ROB and handles it precisely at commit/retire, flushing all younger instructions and discarding their results\
(e) Caches hide the large DRAM latency; a cache hit is much faster than a miss, so access timing reveals which addresses were touched (even speculatively), leaking data
