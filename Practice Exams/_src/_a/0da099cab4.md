(a) Write allocate (fetch the block into the cache, then write it) or no-write allocate / write around (update memory only, do not load the block).\
(b) Write allocate: data written and soon read/rewritten (e.g. updating array elements in a loop), later accesses hit. No-write allocate: data written but not read soon (e.g. initializing / zeroing a large buffer, streaming output), avoids polluting the cache.\
(c) Write-back caches use write allocate: the write must go into a cached block (marked dirty) to be deferred; writing around would send every write to memory, defeating write-back.
