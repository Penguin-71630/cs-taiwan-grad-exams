(a) A blocking RPC suspends the caller until completion/reply; nonblocking calls return immediately with a handle or would-block status, with completion checked later. Buffers preserve pending data; client/server execute independently, and either may itself block on network or storage I/O.\
(b) Install a timeout signal handler using `sigaction` without `SA_RESTART`; `alarm`/a timer interrupts an interruptible blocked call with `EINTR`. On timeout, stop retrying and close/cancel the request; cancelling server-side work requires a cancellation protocol.\
(c) Kernel marks the signal pending, checks masks/disposition before returning to user mode, and performs the default action or saves registers/mask and builds a user signal frame. The user handler executes; `sigreturn` restores context/mask, and the interrupted call resumes, restarts or returns `EINTR` as applicable.
